# Results and Test Evidence

## Important note

The files in this folder include **illustrative example data** created for repository demonstration. They are **not claimed as measurements from the user's physical prototype**.

Before submitting the project as a completed hardware project, replace the illustrative dataset with readings captured from the actual sensor.

## Example workflow

For each known color:

1. Place the object at a fixed distance.
2. Keep lighting as constant as possible.
3. Open Serial Monitor at 9600 baud.
4. Record R, G and B readings.
5. Record the LCD classification.
6. Repeat each color several times.
7. Calculate detection accuracy from the actual observations.
